PHP NO PFSENSE
/usr/local/bin/php e um arquivo executavel, nao uma pasta.
Confirme o caminho com:
  command -v php
  which php
  ls -l /usr/local/bin/php*

A pasta que precisa ser criada e /root/scripts:
  mkdir -p /root/scripts

Depois copie pfsense_zbx.php para /root/scripts/pfsense_zbx.php.
Use no UserParameter o caminho retornado por command -v php.
